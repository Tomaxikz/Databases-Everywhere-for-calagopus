# Databases Everywhere Extension

Included Calagopus extension release: **1.0.1**.

Before installing this Calagopus extension, install and configure the DatabasesEverywhere daemon by following the [official DatabasesEverywhere instructions](https://github.com/Tomaxikz/DatabasesEverywhere).

After the daemon is running, upload `com_tomaxikz_databaseseverywhere.c7s.zip` through the Calagopus Extensions page.

The matching extension source is provided in `com_tomaxikz_databaseseverywhere-1.0.1-source.zip`.
